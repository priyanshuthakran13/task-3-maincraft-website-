# Nova Studio — Maincrafts Technology Internship Task 3

A responsive multi-page website built with plain HTML, CSS and JavaScript.

## Pages
- `index.html` — Home page
- `about.html` — About page
- `services.html` — Services page
- `contact.html` — Contact form with client-side validation and LocalStorage saving
- `submissions.html` — View, search, delete and export saved submissions

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Recommended: install the **Live Server** extension.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Submit a test message from Contact, then open Submissions.

You can also open `index.html` directly in a modern browser.

## Features
- Responsive desktop, tablet and mobile layouts
- Mobile navigation menu
- Light/dark theme toggle (preference is saved)
- Animated cursor glow on mouse devices
- Pointer-following/parallax image movement
- Scroll reveal animations
- Contact form validation (name, email, message and confirmation)
- LocalStorage persistence
- Submissions search, individual delete, clear all and CSV export
- Accessible labels, status messages and reduced-motion support

## Notes
- Contact submissions are saved only in the current browser/device. This is a front-end demo, not a server-backed contact service.
- Images and Google Fonts are loaded from external services, so an internet connection is needed for those assets.
- The brand/content is a sample design. Replace Nova Studio details with your own or the company-approved branding before final submission.
